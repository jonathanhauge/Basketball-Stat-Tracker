# Bench Tracker

In-game bench tracker for Fairmont Firebirds Basketball: possessions, player and team fouls, timeouts, jump balls, live efficiency stats, and a PDF game report.

Open the site in Safari on the iPad, tap Share, then Add to Home Screen. After the first visit it works with no internet.

Everything you enter is saved only on that device. Use Game setup > Back up and restore to keep a copy.
